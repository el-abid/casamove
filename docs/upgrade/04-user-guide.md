# CasaMove user guide

## Passenger portal

- Open `/fr`, `/ar` or `/en`. Search by French name, Arabic name or common spelling in the two station fields. Choose a suggestion before calculating. Both fields support arrow keys and Enter.
- Use Itinéraires to choose an optimisation and optionally exclude lines or a station. Open the intermediate stop list to see stations, transfer walks and final destination directions. A route's duration is an estimate.
- Réseau shows the schematic and the geographic station view. Use line filters, zoom, scroll or drag, and open the station directory for keyboard selection. Geographic position access is optional.
- Start a route to open Travel Companion. Confirm each step manually. Pause and resume in the same tab, even after reload. When a new disruption affects your remainder, accept the suggested route when available.
- Sign in to save a named itinerary or add a favourite station. Use Mon espace to edit saved trips, see recent complaint or report changes, set preferences and view your existing subscription. The demo subscription card is invalid for travel.
- Community Pulse accepts a station or segment observation. Administration can review and link it to a simulation. Notification Centre shows updates related to your account and saved trips.
- Visit the portal while online before going offline. Supported browsers can install the application from their menus. The offline shell includes the public planner and schematic. The traffic panel labels unavailable status and the last check.

## Control Tower

An administrator opens `/admin/mobility` from the agent console. Select an effect, line, and stations when required. Enter a title and explanation and optionally a planned end. Publishing exposes the message in the passenger traffic panel. Resolve from the incident list. Revision checks prevent overwriting competing edits.

The reports panel shows the category, location and moderation status. Select a disposition and optionally associate an incident on the same line. The original complaints and Voice of Customer console are available from the Control Tower's back link.
